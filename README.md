## 🧭 About me

I've spent 5+ years learning programming and building projects. I'm most interested in **backend engineering, distributed systems, machine learning and system design**.

I like to understand how technologies work under the surface: how they are designed, optimized and scaled, rather than only how to use them. My long-term goal is to contribute to technologies that push the industry forward and to work on challenging engineering problems.
